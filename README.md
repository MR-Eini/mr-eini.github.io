# mr-eini.github.io

Personal website.

## Viewing the site locally

You can preview the latest version of the site without deploying it:

1. **Open the static files directly**
   - Double-click `index.html` in your file browser or open it from the terminal: `open index.html` (macOS) or `xdg-open index.html` (Linux).

2. **Run a lightweight dev server** (avoids any browser security restrictions with local files):
   - Use Python 3: `python3 -m http.server 8000`
   - Then visit http://localhost:8000 in your browser.

No additional build steps or dependencies are required.
